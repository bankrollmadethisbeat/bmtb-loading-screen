**FREE** FiveM script by **BMTB Scripts**.

**Version:** v2.0.0  |  **Standalone** — no framework, no Lua required

## About

FiveM join experience — video playlist, music player, staff list, visitor notes, and keyboard overlay. Owners set it up in `setup.html`.

## Features

- Video playlist — YouTube links or local MP4/WebM, skip and volume controls
- Music player with now-playing, shuffle, and load-progress bar
- Staff list — owner, developer, and admin with photos and bios
- Visitor notes — players leave a message that scrolls for later joiners
- Keyboard overlay — default FiveM/GTA binds plus custom server keys
- setup.html color presets — ice, cyan, gold, violet, crimson, or custom
- No Lua required — Discord and store buttons, no framework dependency
